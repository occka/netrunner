# План NEURAL: фото, режимы Work / Play, своя папка, игра

Состояние на 4 ноября 2026 года: **реализовано в ветке `release/0.8.3`**, релиз только по слову пользователя. Подробности живут в `docs/ARCHITECTURE.md` и `docs/SECURITY.md`; здесь то, что выяснили и решили.

---

## Что проверено вживую (ключ пользователя, gemini-3.5-flash-lite)

- `generateContent` по-прежнему полностью поддерживается, хотя Google называет его Legacy; срока отключения нет. Остаёмся на нём. `POST /v1beta/interactions` с ключом тоже отвечает, это путь на будущее. Там `store` по умолчанию включён: на бесплатном тарифе запросы хранятся 1 день.
- Без `thoughtSignature` при возврате результата инструмента Gemini отвечает 400. Подпись есть только у первого из параллельных вызовов. Части ответа надо возвращать как есть.
- Встроенный Python рядом с функциями требует `toolConfig.includeServerSideToolInvocations: true`, иначе 400.
- Фото через `inlineData` работают: 64x64 стоит около 1100 токенов.
- Модели бывают заняты (503): `gemini-3.1-flash-lite` отказал, `3.5` ответила.

## Лимиты бесплатного тарифа (страница AI Studio пользователя, 4 ноября 2026)

| Модель | В минуту | Токенов в минуту | В день |
|---|---|---|---|
| Gemini 3 Flash, 3.8 Flash, 2.5 Flash | 5 | 250K | **20** |
| Gemini 3.1 Flash Lite, 3.5 Flash Lite | 15 | 250K | **500** |
| Gemma 4 26B, 31B | 30 | **16K** | 14.4K |

Вывод: игра идёт на Flash Lite, у Flash только 20 запросов в день, а одно сообщение агента может съесть несколько. Порог истории около 60 000 токенов выбран из расчёта на 3 запроса в минуту при лимите 250K.

## Gemma 4 (проверено вживую 4 ноября 2026)

Умеет инструменты (с подписями), системные инструкции и фото; по-русски пишет не хуже Flash Lite. Основной не подходит:
- 16K токенов в минуту: запрос несёт историю и файлы, поэтому большой дневной лимит не достижим. Партия упирается в этот лимит уже через десяток-другой ходов.
- Ненадёжна: gemma-4-26b-a4b-it ответила на 6 запросов из 14, gemma-4-31b-it на 1 из 6 (остальное ошибки 500 и 503). Время ответа от 1 до 83 секунд. Это один замер в один день.

Её можно выбрать в списке моделей вручную. Как запасную не добавляли: 16K и задержки чаще мешают, чем помогают.

## Решения

- У каждого чата своя папка, доступ только к ней. Режим хранится в чате, новый чат всегда Work.
- `execute_python`, который предлагал Gemini, **не запускает код на ПК**: это встроенное выполнение Google, только в Work. В Play его нет: Flash Lite использовала Python как черновик для размышлений и потом замолкала.
- Нет удаления и нет запуска программ. Запись без подтверждений, зато Undo у каждого изменения.
- Игровые инструкции внутри режима Play, без отдельного экрана шаблонов.
- «Продолжить в новом чате» с переносом папки **не делаем** (решение пользователя): кампания живёт в одном чате.

## Открытые вопросы

- **Условия для ЕЭЗ, Великобритании и Швейцарии:** в условиях Gemini API сказано, что приложения для пользователей из этих регионов могут работать только с платным тарифом. Пользователь смотрит AI Studio на немецком; его регион неизвестен. Для личного использования решает он сам.
- **Интерактивный API и серверные агенты** (`/v1beta/agents`, `/v1beta/environments`): не нужны для этой задачи, потому что агент работает с локальными файлами. Доступны ли они на бесплатном тарифе, не проверялось.
- **Не проверено вживую:** поведение API при превышении лимита токенов, настоящий лимит 429 и его заголовки (разбор проверен только на примерах).
